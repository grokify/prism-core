# Release Notes v0.3.0

This release adds developer productivity and AI-enhanced framework support to prism-core.

## New Features

### Developer Productivity Frameworks

Added support for industry-standard developer productivity measurement frameworks:

- `FrameworkSPACE` - Satisfaction, Performance, Activity, Communication, Efficiency (Forsgren et al., 2021)

### AI-Enhanced Frameworks

Added AI-modified versions of established frameworks for measuring AI-assisted development:

- `FrameworkAIDORA` - AI-Modified DevOps Research and Assessment
- `FrameworkAISPACE` - AI-Modified Developer Productivity Framework

### New Helper Functions

- `DeveloperProductivityFrameworks()` - Returns SPACE and AI-SPACE frameworks
- `AIFrameworks()` - Returns all AI-enhanced frameworks (NIST AI RMF, AI-DORA, AI-SPACE)

## Usage

```go
import prism "github.com/grokify/prism-core"

// Get all developer productivity frameworks
devProdFrameworks := prism.DeveloperProductivityFrameworks()
// Returns: ["SPACE", "AI_SPACE"]

// Get all AI-enhanced frameworks
aiFrameworks := prism.AIFrameworks()
// Returns: ["NIST_AI_RMF", "AI_DORA", "AI_SPACE"]

// Get display names
name := prism.FrameworkDisplayName(prism.FrameworkSPACE)
// Returns: "SPACE"
```
