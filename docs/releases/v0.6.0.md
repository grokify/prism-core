# Release Notes v0.6.0

This release adds a shared product-line primitive, so planning tools and
execution tools can point roadmap items and work at the same product lines and
classify them the same way.

## New Features

### Product Lines (`productline.go`)

Added `ProductLine`, a top-level product concept and a peer of the initiative:

- `ID`, `Name`, and `Kind` identify the line. Source tools name it differently
  (Aha! "product", Productboard "component", Jira Product Discovery "project"),
  and an integration maps each to these fields.
- `ParentID` places the line under a product group or business unit.
- `MarketPosition` classifies the line by market growth and share. Like
  `ParentID`, it is set by a person and never overwritten by a sync.

`ProductLineKind` constants place a line on the portfolio axis:

- `ProductLineKindVertical` - a line with its own market position
- `ProductLineKindPlatform` - a shared enabler across lines
- `ProductLineKindMarket` - a go-to-market category, which is not a product line and has no market position

`MarketPosition` constants, inspired by the Boston Consulting Group's
growth-share matrix, with an enabler position for a shared platform:

- `MarketPositionStar`, `MarketPositionCashCow`, `MarketPositionQuestionMark`,
  `MarketPositionDog`, and `MarketPositionEnabler`

The values match the option IDs of prism-roadmap's `MarketPositionDimension`,
the rubric for backing a position with evidence.

`ProductLineScope` says whether an initiative is line-specific, cross-line, or
portfolio-wide. It is derived with `ScopeFor`, and its zero value is
`ScopeUnknown`, so an unset scope never reads as an answer.

### New Helper Functions

- `ProductLine.Validate()` - Reports a missing ID or name, an unknown kind or market position, or a market position on a market category
- `AllProductLineKinds()`, `ValidProductLineKind()` - List and check kinds
- `AllMarketPositions()`, `ValidMarketPosition()` - List and check market positions
- `ScopeFor(referenced, total)` - Derives an initiative's scope from the lines it references

## Usage

```go
import prism "github.com/grokify/prism-core"

line := prism.ProductLine{
	ID:             "analytics",
	Name:           "Analytics",
	Kind:           prism.ProductLineKindVertical,
	MarketPosition: prism.MarketPositionStar,
}
if err := line.Validate(); err != nil {
	return err
}

scope := prism.ScopeFor(1, 5) // prism.ScopeLineSpecific
```

See the [product lines guide](../guides/product-lines.md).

## Compatibility

Additive only. No existing types or functions change, and there are no new
dependencies.
