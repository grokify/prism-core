# Release Notes v0.4.0

This release adds support for the SCALE platform engineering framework to prism-core.

## New Features

### Platform Engineering Frameworks

Added support for the SCALE framework for measuring platform engineering effectiveness:

- `FrameworkSCALE` - Standards, Consumption, Automation, Leverage, Effectiveness

### SCALE Aspects (`scale.go`)

Added constants and helpers for the five SCALE aspects:

- `SCALEAspectStandards` - Do executable engineering standards exist?
- `SCALEAspectConsumption` - Are teams using them (adoption) and using them correctly (conformance)?
- `SCALEAspectAutomation` - How much is enforced automatically?
- `SCALEAspectLeverage` - What reuse and engineering capacity do they create?
- `SCALEAspectEffectiveness` - Did engineering and business outcomes improve?

Consumption kinds distinguish adoption from conformance:

- `SCALEConsumptionKindAdoption`
- `SCALEConsumptionKindConformance`

### New Helper Functions

- `PlatformEngineeringFrameworks()` - Returns platform engineering frameworks (SCALE)
- `AllSCALEAspects()` - Returns all SCALE aspect constants in canonical order
- `ValidSCALEAspect()` - Checks if an aspect value is valid
- `SCALEAspectLetter()` - Returns the single-letter abbreviation for an aspect
- `SCALEAspectDisplayName()` - Returns a human-readable name for an aspect
- `SCALEAspectDescription()` - Returns the question each aspect answers
- `AllSCALEConsumptionKinds()` - Returns all consumption kind constants
- `ValidSCALEConsumptionKind()` - Checks if a consumption kind value is valid

## Usage

```go
import prism "github.com/grokify/prism-core"

// Get all platform engineering frameworks
peFrameworks := prism.PlatformEngineeringFrameworks()
// Returns: ["SCALE"]

// Walk the SCALE aspects
for _, aspect := range prism.AllSCALEAspects() {
	letter := prism.SCALEAspectLetter(aspect)
	name := prism.SCALEAspectDisplayName(aspect)
	question := prism.SCALEAspectDescription(aspect)
	fmt.Printf("%s - %s: %s\n", letter, name, question)
}

// Get display name for the framework
name := prism.FrameworkDisplayName(prism.FrameworkSCALE)
// Returns: "SCALE"
```
