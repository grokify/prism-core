## [v0.2.0] - 2026-06-06 ([`dee2c08`](https://github.com/grokify/prism-core/commit/dee2c08))

### Highlights

- Remove Priority and MoSCoW types - use github.com/grokify/priority-frameworks instead

### Breaking

- Removed `PriorityCritical`, `PriorityHigh`, `PriorityMedium`, `PriorityLow` constants ([`4d7a7c6`](https://github.com/grokify/prism-core/commit/4d7a7c6))
- Removed `ValidPriority()` and `PriorityWeight()` functions ([`4d7a7c6`](https://github.com/grokify/prism-core/commit/4d7a7c6))
- Removed `MoSCoWMust`, `MoSCoWShould`, `MoSCoWCould`, `MoSCoWWont` constants ([`4d7a7c6`](https://github.com/grokify/prism-core/commit/4d7a7c6))
- Removed `ValidMoSCoW()` and `MoSCoWWeight()` functions ([`4d7a7c6`](https://github.com/grokify/prism-core/commit/4d7a7c6))

### Upgrade Guide

- Replace `prism.PriorityCritical` with `pf.Severity().Parse("critical")` from priority-frameworks
- Replace `prism.ValidPriority(p)` with `pf.Severity().Parse(p) != nil`
- Replace `prism.PriorityWeight(p)` with `pf.Normalize(pf.Severity(), p)`
- Replace `prism.MoSCoWMust` with `pf.MoSCoW().Parse("must")`

### Documentation

- Update README frameworks section ([`dd955ee`](https://github.com/grokify/prism-core/commit/dd955ee))
